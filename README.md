# Personal Portfolio Website 🌐

## 📌 Description
This is my personal portfolio website showcasing my skills, projects, and contact details. It also includes a contact form connected to a MySQL database.

---

## 🚀 Features
- Responsive portfolio design
- About, Skills, and Contact sections
- Contact form with backend (Node.js)
- Data stored in MySQL database

---

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- Node.js (Express)
- MySQL

---

## ⚙️ Run Project

```bash
npm install
node server.js
Open:
http://localhost:5000
